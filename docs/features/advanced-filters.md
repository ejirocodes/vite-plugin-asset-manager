# Advanced Filters

Filter assets by size, modification date, and file extension to quickly find what you're looking for.

## Size Filters

Filter assets by file size using presets:

| Preset | Range |
|--------|-------|
| **Any** | No size filter |
| **Small** | Under 10 KB |
| **Medium** | 10 KB – 100 KB |
| **Large** | 100 KB – 1 MB |
| **Extra Large** | Over 1 MB |

## Date Filters

Filter assets by when they were last modified:

| Preset | Range |
|--------|-------|
| **Any** | No date filter |
| **Today** | Modified today |
| **Last 7 days** | Modified in the past week |
| **Last 30 days** | Modified in the past month |
| **Last 90 days** | Modified in the past quarter |
| **This year** | Modified this year |

## Extension Filters

Filter by specific file extensions. Select one or more extensions from the list of extensions found in your project.

## Combining Filters

All filters can be combined with each other and with the search bar. For example, you can search for "logo" while filtering to images over 100 KB modified in the last 7 days.

Filters are applied client-side for instant results.
