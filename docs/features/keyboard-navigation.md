# Keyboard Navigation

The asset manager supports full keyboard navigation for efficient asset management without a mouse.

## Global Shortcuts

| Shortcut | Action |
|----------|--------|
| <kbd>Option</kbd> + <kbd>Shift</kbd> + <kbd>A</kbd> | Toggle asset manager panel |
| <kbd>Escape</kbd> | Close the panel |

## Grid Navigation

| Shortcut | Action |
|----------|--------|
| <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | Move between asset cards |
| <kbd>j</kbd> / <kbd>k</kbd> | Move down / up (vim-style) |
| <kbd>Enter</kbd> | Open preview panel for focused asset |
| <kbd>Space</kbd> | Toggle selection of focused asset |

## Action Shortcuts

| Shortcut | Action |
|----------|--------|
| <kbd>p</kbd> | Open preview panel |
| <kbd>c</kbd> | Copy file path |
| <kbd>i</kbd> | Copy import code |
| <kbd>e</kbd> | Open in editor |
| <kbd>r</kbd> | Reveal in Finder/Explorer |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Delete asset (with confirmation) |

## Search

Press <kbd>Cmd</kbd> + <kbd>K</kbd> (or <kbd>Ctrl</kbd> + <kbd>K</kbd>) to focus the search bar from anywhere in the dashboard. The search uses 200ms debounce for smooth typing.
